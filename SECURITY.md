# Security policy

## Reporting

Please report suspected vulnerabilities privately to the repository owner through GitHub's private vulnerability reporting feature. Do not include real credentials, production configuration, or exploit demonstrations. If private reporting is unavailable, open a minimal issue asking for a private contact channel.

## Scope

The repository is an early research MVP. Supported releases and response-time guarantees are not yet established. Reports about unsafe benchmark content, dependency risk, validation bypasses, or accidental sensitive data are welcome.

## Safe use

Never run suggested remediations directly on production. Human review and isolated testing are required.
